월간 한권 개인정보처리방침

최종 업데이트: 2026년 9월 15일

수집하는 개인정보

월간 한권(Bookmonth)은 사용자가 읽은 책의 기록(제목, 저자, 한줄평, 인상 깊은 문장, 평점, 독서 상태 등)을 직접 입력하는 개인용 독서 기록 앱입니다. 앱은 회원가입이나 로그인을 요구하지 않으며, 이름·이메일 등 사용자를 식별할 수 있는 정보를 수집하지 않습니다.

데이터 저장 위치

  • 등록한 책 기록은 사용자 본인의 Apple iCloud 계정에 CloudKit을 통해 저장됩니다. 이 데이터는 사용자 본인의 iCloud 저장 공간에 있으며(Apple의 개인정보처리방침 적용, https://www.apple.com/legal/privacy/kr/), 개발자는 이 데이터에 접근할 수 없습니다.
  • 같은 iCloud 계정으로 로그인한 iPhone, iPad, Mac 사이에서 자동으로 동기화됩니다.

카메라

책 뒤표지의 ISBN 바코드를 스캔하는 기능에 카메라를 사용합니다. 스캔은 기기 안에서 실시간으로 처리되며, 사진이나 영상은 저장되거나 외부로 전송되지 않습니다.

외부 서비스 호출

책 정보를 자동으로 채우기 위해 ISBN 번호를 아래 외부 서비스로 전송합니다. 전송되는 정보는 ISBN 번호뿐이며 사용자를 식별할 수 있는 정보는 포함되지 않습니다.

  • 국립중앙도서관 서지정보(SEOJI) API (nl.go.kr)
  • 카카오 책 검색 API (kakao.com)
  • Open Library (openlibrary.org)

제3자 공유

월간 한권은 광고, 분석(analytics), 트래킹 SDK를 포함하지 않습니다. 어떠한 개인정보도 제3자와 공유하거나 판매하지 않습니다.

데이터 내보내기 및 삭제

앱 내 설정에서 전체 기록을 JSON 파일로 내보내거나 가져올 수 있습니다. 등록한 책은 언제든 앱에서 직접 삭제할 수 있으며, 삭제 시 연결된 한줄평과 문장도 함께 삭제됩니다. iCloud에 동기화된 데이터는 iOS/macOS의 iCloud 설정에서 직접 관리·삭제할 수 있습니다.

아동의 개인정보

월간 한권은 만 13세 미만 아동을 대상으로 하지 않으며, 아동으로부터 의도적으로 개인정보를 수집하지 않습니다.

Bookmonth Privacy Policy

Last updated: September 15, 2026

Information We Collect

Bookmonth is a personal reading log app in which the user manually enters records of books they've read (title, author, a short review, memorable quotes, rating, reading status). The app requires no account or sign-in and does not collect any information that identifies the user, such as a name or email address.

Where Data Is Stored

  • Book records are stored in the user's own Apple iCloud account via CloudKit. This data resides in the user's personal iCloud storage, governed by Apple's Privacy Policy (https://www.apple.com/legal/privacy/), and the developer has no access to it.
  • Data syncs automatically between the user's iPhone, iPad, and Mac signed into the same iCloud account.

Camera

The camera is used to scan the ISBN barcode on the back of a book. Scanning is processed on-device in real time; no photo or video is saved or transmitted.

Third-Party API Calls

To automatically fill in book details, the app sends the ISBN number to the following external services. Only the ISBN number is sent; no information that identifies the user is included.

  • National Library of Korea SEOJI API (nl.go.kr)
  • Kakao Book Search API (kakao.com)
  • Open Library (openlibrary.org)

Third-Party Sharing

Bookmonth contains no advertising, analytics, or tracking SDKs. No personal information is shared with or sold to any third party.

Data Export and Deletion

The app's settings let you export all records to a JSON file, or import one. Any book can be deleted from within the app at any time; deleting a book also deletes its review and quotes. Data synced to iCloud can be managed or deleted directly from iOS/macOS iCloud settings.

Children's Privacy

Bookmonth is not directed at children under 13, and we do not knowingly collect personal information from children.
